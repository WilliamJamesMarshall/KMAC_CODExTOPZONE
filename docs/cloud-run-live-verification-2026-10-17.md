## 공유 주소

**[OSS AX 매칭 서비스](https://oss-ax-591110969614.asia-northeast3.run.app/)**

로그인 없이 PC·휴대폰에서 접속할 수 있는 HTTPS 주소다. 홈페이지 URL 입력 → 분석 시작 → 업무 선택 → 추천 공급기업 확인 → 보고서 다운로드 순서로 사용한다. 공개 전에는 인증 없는 요청이 403으로 차단되는 것을 확인했으며, 비공개 기능 검증 후 `allUsers`에 서비스 호출 권한만 부여했다.

| 최종 통계 | 시험 분석 수락 3건: HTTP 200 2건, 의도한 차단 주소의 422 1건. 실행 잠금 해제 확인 |

팜에이트의 필수 출력 누락은 0개였다. 단블은 업무·추천·다운로드가 동작했지만 `business_model.value` 1개가 비어 있었고, 비공개 진단 기록에서 핵심사업의 직접 근거 부족을 확인했다. 이 값은 추정 문구로 채우지 않았다. 따라서 배포·접속·동적 수집·UI·PDF 동작 확인과 추천 내용의 완전성을 구분한다.

실제 분석에서 반환된 연락처·기업 정보는 공개 홈페이지 및 기존 공급기업 데이터의 시험 결과다. 모든 사이트의 수집 가능성과 추천 적합성을 보장하는 검증은 아니다. 정상 분석 결과 자체는 서버에 자동 보관하지 않으며, 실패·불완전 진단은 비공개 Storage에 기록한다.

## 사용 시 참고

분석 한도는 사용자별이 아닌 **공유 서비스 전체 월 100건**이다. 이번 시험에서 3건을 사용했으며 시험 직후 잔여 한도는 97건이다. 수락 후 실패한 요청도 한도에 포함한다. 무료 사용량을 활용하지만 외부 AI, 이미지 보관·전송 등의 비용까지 월 0원을 보장하지 않는다. 전체 프로젝트 월 1,000원 알림과 Cloud Run 월 1,000원 지출 제한이 설정되어 있으며, 지출 제한은 크레딧 차감 전 추정 비용과 반영 지연의 영향을 받는다.

최소 인스턴스가 0이므로 한동안 사용하지 않은 뒤 첫 접속에는 기동 대기가 생길 수 있다. 실제 분석에는 수 분이 걸릴 수 있으므로 완료될 때까지 페이지를 유지한다. 다른 분석이 진행 중이면 잠시 후 다시 요청한다.
