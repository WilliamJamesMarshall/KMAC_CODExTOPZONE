# 전체 DB 공급기업 추천 확대 — 구현·검증 결과

2026-10-17 · 로컬 OSS 적용 버전 `b297b3ba92144e57`

전체 1,428개 공급기업의 원문을 검색에 연결하고, 검증을 통과한 업체만 업무당 최대 2곳 추천하도록 수정했습니다. **사용자 지시에 따라 1~62번 URL 전수 재점검은 수행하지 않았습니다.** 이번 검증에서는 새 URL 분석 요청도 보내지 않았습니다.

## 실제 DB 연결 결과

| 구분 | 검색에 편입된 업체 | 표시 필수정보 검증 통과 | 홈페이지 정보 보완 필요 |
|---|---:|---:|---:|
| 기존 추천 대상 | 112 | 108 | 4 |
| 기존 범위 밖 | 1,316 | 1,221 | 95 |
| 전체 | **1,428** | **1,329** | **99** |

1,329곳은 **추천 후보 자격**을 갖춘 수입니다. 실제 업무별 추천은 원문·업무 적합성 감사까지 통과해야 합니다. 99곳도 원문 검색에는 포함되지만, 홈페이지가 비어 있거나 유효한 단일 URL로 확인되지 않아 최종 추천 후보에서 보류합니다. 임의 주소나 대체 문구를 넣어 정상 처리하지 않았습니다. 주소·전화·대표자·전문분야·솔루션 설명의 필수값은 전체 1,428곳에 존재했습니다. 홈페이지 검사는 등록 문자열의 유효성 검사이며, 각 사이트의 현재 접속 가능 여부를 전수 조사한 결과는 아닙니다.

기존 112곳은 DB ID 연결과 솔루션 원문이 모두 보존됐습니다. 원문이 바뀌거나 연결이 사라진 업체는 0곳입니다. 보류된 기존 4곳은 케이슬립케어(I010), 마지글(I108), 다연에이아이솔루션(I317), 리브리프(I318)입니다. 케이슬립케어의 워크북 값은 설명이 붙은 복수 앱 URL이며, 나머지 세 곳의 워크북 홈페이지 값은 ‘미기재’입니다. 이들을 신규 업체와 같은 표시 정보 기준으로 처리했습니다.

## 변경한 동작

- 전체 연도별 DB 등록자료를 1,000건씩 끝까지 읽고, DB UUID·등록번호·원문 회사명을 대조합니다. 이름만 같은 업체의 자료를 합치지 않습니다. 기존 워크북 ID는 출처가 확인된 DB ID의 별칭으로 연결합니다.
- 솔루션 구간별 원문 검색에 기존 Task 연결, 기능·산출물, 적용 영역·입력 데이터 검색을 함께 사용합니다. ‘기록’ 같은 넓은 단어가 ‘양식장’ 같은 구체적 적용 영역을 밀어내지 않도록 조정했습니다. 업체별 예외 목록은 추가하지 않았습니다.
- 후보 최대 24곳 중 초기 12곳을 감사한 뒤 비교합니다. 통과 업체가 없으면 남은 후보를 총 24곳 한도에서 검토합니다. 한도 도달은 진단에 남기며 DB 전체에 업체가 없다고 판정하지 않습니다.
- 솔루션명·원문 구간·원래 업무의 지원 산출물, 실제 기능, 적용 영역, 설명의 정직성, 담당자 최종 판단 기준을 기존과 같이 검증합니다. 잘못 고른 산출물은 원래 업무에 존재하는 산출물 안에서 1회 교정하고 재감사합니다. 실제 기능 부족이나 적용 영역 충돌은 계속 제외합니다.
- 감사 통과 후 선택한 산출물 전체 지원, 일부 지원과 공개된 미확인 항목 수, 검색 순서 순으로 최대 2곳을 선정합니다. 일부 지원은 화면과 PDF에 범위·미확인 기능을 표시합니다. 적합 업체가 한 곳이면 한 곳만 출력합니다.
- API 최종 목록, 화면, PDF 요청을 업무당 2곳으로 맞췄습니다. PDF 서버는 한 업무에 3곳을 넣은 요청을 HTTP 422로 거부하며, 출력 검사기도 초과를 오류로 기록합니다. 추천 업무 수 최대 3개는 유지했습니다.
- 카탈로그는 서버에서 1시간 캐시합니다. 갱신 실패 시 불완전 자료로 교체하지 않고 해당 요청에 원천정보 조회 실패를 기록합니다. DB 수정·마이그레이션은 하지 않았습니다.

## 업무를 고정한 실제 추천 검사

이전 진단에 저장된 기업 이해·업무·입력·메커니즘·산출물을 그대로 사용했습니다. 홈페이지 수집이나 업무 재생성 없이 전체 DB 검색과 실제 추천 생성·독립 감사만 실행했습니다.

| 고정 업무 | 실제 검토 / 감사 통과 | 최종 추천 | 추천 단계 소요시간 |
|---|---:|---|---:|
| 타이드풀 N013 양식장 생육·환경 상태 검토 | 12 / 2 | 플렉싱크 FlexPulse, 데이터에듀 어장분석모니터링솔루션 | 약 70초 |
| 노을 J014 염색 공정 품질 검토 | 12 / 2 | 아이디비 Quartz Go AI, 베이스온 AI-Analytics | 약 75초 |
| 기존 정상 업무 J020 연구자료 근거 검색 | 12 / 7 | 빅시프트, 레인메이커 | 약 90초 |

각 업무는 최대 24곳을 검색 후보로 확보했고, 초기 12곳에서 통과 업체를 확보해 추가 검토를 하지 않았습니다. 위 시간은 URL 전체 분석 시간이 아닙니다.

기존 정상 추천 업체 페르소나에이아이(F014)는 새 경로에서도 초기 후보에 들어와 독립 감사를 통과했습니다. 최종 2곳은 감사 결과를 비교해 선정되므로 이전 업체명이 반드시 그대로 표시되는 구조는 아닙니다.

나모웹비즈도 양식장 업무의 초기 후보에 포함됐지만 이번 독립 감사에서는 원문의 최적제어 알고리즘만으로 ‘검토할 관리 방향’ 산출물이 직접 확인되지 않는다고 판정해 제외했습니다. 데이터에듀는 기존 조사 때 제외됐던 광범위한 환경 분석 주장 대신, 실제 원문의 어류 활동 측정·외상 탐지에 한정한 카드로 일부 지원 감사를 통과했습니다. 환경 추세 통합 분석과 관리 방향 제시를 지원한다고 표시하지 않았습니다. 특정 업체를 통과시키기 위해 감사 기준을 낮추지는 않았습니다.

모델의 범위 판단에는 변동 가능성이 있으며, 이 세 고정 사례가 62개 URL 또는 모든 업무의 추천 품질 검증을 대체하지는 않습니다.

## 자동·화면·PDF 검증

- 실제 워크북 계약 검사를 포함한 **148개 테스트 통과, 실패·건너뜀 0개**. 신규 12개 검사는 워크북에 없는 업체 연결, 기업 식별 충돌·필수정보 누락 차단, 1,000건 이후 페이지 조회, 반복 페이지 탐지, 갱신 실패, 적용 영역 검색, 초기 12곳 전체 비교, 검토 24곳 한도, 1곳만 적합한 경우, 교정 범위, PDF·출력 2곳 제한을 확인합니다.
- 자바스크립트 구문 검사와 변경 공백 검사 통과.
- 실제 Edge에서 N013/J014의 고정 결과를 직접 표시한 후 보고서 버튼으로 PDF 2개를 다운로드했습니다. URL 입력·검색 요청은 **0회**입니다. 화면 업체명과 PDF 요청 업체명·추천 설명·일부 지원 안내가 일치합니다. 잘못된 3곳 결과를 화면에 넣어도 표시·PDF 요청은 2곳이며, 서버로 직접 보낸 3곳 PDF 요청은 거부됩니다.
- 다운로드 PDF **6페이지 + 4페이지 = 10페이지**를 전부 렌더링해 시각 확인했습니다. 내보낸 64개 항목을 대조했으며 누락·본문 영역 이탈·널 문자 없이 글꼴이 포함됐습니다. 이 파일은 개별 고정 업무 검증용이며 URL 전체 재점검 보고서가 아닙니다.

## 적용 상태와 남은 범위

로컬 OSS 서버를 위 버전으로 재시작했습니다. 브라우저를 새로고침하면 새 코드가 적용됩니다. 외부 서비스 배포나 DB 쓰기는 수행하지 않았습니다. 기존 보고서를 덮어쓰지 않고 이번 증거를 별도 폴더에 저장했습니다.

홈페이지 정보 99곳은 출처를 확인해 DB 등록정보를 보완하면 같은 경로에서 후보 자격을 다시 판단합니다. 모든 공급기업을 무조건 추천하거나 검증되지 않은 필드를 채우지는 않습니다.

**1~62번 URL의 검색창 순차 입력·전체 필드 판정·보고서 일괄 다운로드는 별도 지시 전까지 수행하지 않습니다.** 따라서 이번 결과로 62개 모두 정상이라고 결론 내리지 않았습니다.

검증 원본: `reports/full-pool-20261017/`의 `catalog-read-check.json`, `verified-N013.json`, `verified-J014.json`, `verified-J020.json`, `tests-final.log`, `ui-pdf-verification.json`, `pdf-quality-check.json`. 코드는 `supplier_catalog.py`, `supplier_policy.py`를 추가하고 프로필 조회·검색·추천 감사·결과 구성·화면·PDF·출력 검사 경로를 수정했습니다.
